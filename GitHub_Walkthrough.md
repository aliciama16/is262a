This guide is to help you through our in-class lab!

# 1. Create Your GitHub Account
* Go to github.com → Sign up
* Enter email → password → username → Create Account
* Verify email with the emailed code
* You’ll be brought back to the sign in page → Sign in

# 2. Create Your First Repository & Upload Your First File
* Top + → New repository
* Name it "my-first-repo"
* Toggle on "Add README"
* Click "Create Repository"
* Click on “Add File” → “Upload files”
* Upload an image -
    It can be your pet, one of your favorite memes, places, food, etc. (Name the image file clearly)
* Add an “extended description” in the box about WHAT you are uploading
* Make sure it says “commit directly to the main branch”
* Click “Commit Changes”

# 3. Create Your First README
* Go to your repository
* To the upper right of README.md click the pencil “edit” button
* Open README.md → Edit
* Add 2 lines -
    Your first name
    A description of why you created this repository (for class)
* Click the big green “Commit changes…” button
* Can add a extended description of what changes you made in the README -> commit changes to the main branch
* <b>YOU HAVE A REPOSITORY WITH A FILE & A README!</b>

# 4. Edit Your README
* Oops,  I forgot something… you'll have to make a change to your README 
* To the upper right of README.md click the pencil “edit” button
* Add a line to tell us who your favorite musician is
* Click the big green "Commit changes..." button

# 5. Save your Week 5 Python code to GitHub from Google CoLab
* Open your Google Colab notebook from Week 5 and give it a descriptive name like IS262A-Python-Intro
* From the top menu → File → Save a copy in GitHub
* Connect to GitHub! Follow the prompts and authorize Google CoLab to access GitHub. If it asks for a repository, select the one you just made (my-first-repo), keep it on the main branch
* Return back to GitHub and open your repository & you should see your code!

(Note: remember, GitHub does not create a live connection from Google Colab. If you make more changes in your Colab code, you will need to save to GitHub again to overwrite and save the updated copy)

# 6. Find your repository URL
* Go to profile → repositories → click on my-first-repo → copy & save the URL from your browser address bar (it should look something like this: https://github.com/yourusername/my-first-repo)
* Save this link - you'll need it for the next step

# 7. Add Yourself to the 2026 Class Roster (Using a Pull Request)
* Open my class repository (https://github.com/aliciama16/is262a/) → then click on students folder → 2026 folder 
* Open the /_TEMPLATE.md, click the "edit"/pencil button
* You'll be told you need to fork this repository to propose changes. So, fork this repository!
* Now you can copy this template
* Click back into 2026 and select Add file → Create new file
* To name your file add your username after & add .md (e.g. is262a/students/aliciama16.md)
* Paste template in the box below, add your info + your repo link.
* Click green Commit changes button → propose changes
* Now click Create pull request
* You're given the opportunity to explain why you're proposing a change/ what you changed. You can type something here or just select "create pull request" again
* I will approve it - Github auto-forks and auto-branches when you propose a change
* Wait and see!
